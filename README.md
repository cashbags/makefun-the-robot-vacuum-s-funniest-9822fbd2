**The Robot Vacuum's Funniest Excuse** — the excuse a robot vacuum gives
for missing a spot:

> I left a grain of rice there as a marker. In 12 days it was promoted to landmark. I clean around it out of respect.

115 characters, one line. It won a 66-game pairwise tournament over 12
candidates in empty lanes (DESIGN.md).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`
with no trailing newline. No clock, no randomness, no network.
